# project-4-practice

Интерактивный веб-калькулятор, имитирующий интерфейс современных мобильных приложений (в стиле iOS). Приложение позволяет выполнять базовые арифметические операции, работать с процентами и дробными числами. Интерфейс полностью адаптивен и включает анимации для улучшения пользовательского опыта.
Основные функции:
Сложение, вычитание, умножение и деление.
Вычисление процентов.
Работа с отрицательными числами и плавающей запятой.
Плавная визуальная отдача (анимация) при наведении и нажатии на кнопки.
Обработка ошибок (например, деление на ноль).

Стек технологий

HTML5: Структура калькулятора, разметка сетки кнопок и дисплея.
CSS3:
Flexbox: для позиционирования элементов.
Gradients: для создания современного фона страницы.
Transitions & Filters: для плавных анимаций наведения (hover) и активного состояния (active).
JavaScript (ES6+):
DOM API: для обработки кликов и обновления экрана.
Event Delegation: эффективная обработка нажатий через один слушатель на контейнере.
Математическая логика: алгоритм обработки последовательных вычислений.

Инструкция по запуску

Проект является статическим и не требует установки дополнительных зависимостей или сборки

1. Скачайте файлы проекта (index.html, style.css, script.js) в одну папку.
2. Убедитесь, что файлы связаны в HTML (теги <link> для CSS и <script> для JS).
3. Откройте файл index.html в любом современном браузере (Chrome, Firefox, Safari, Edge) двойным кликом.
